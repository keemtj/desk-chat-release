# 데스크챗 (desk-chat)

같은 사무실 Wi-Fi에 있는 사람끼리 화면 아래에 캐릭터를 띄워 두고 잡담하는
macOS 앱입니다. 서버가 없고 대화는 저장되지 않습니다.

이 저장소에는 **배포 파일만** 있습니다. 소스 코드는 비공개입니다.

**[최신 버전 받기 →](https://github.com/keemtj/desk-chat-release/releases/latest)**

## 준비물

- **Apple Silicon 맥** (M1 이상). Intel 맥에서는 실행되지 않습니다.
- **macOS 13 이상**
- 상대방과 **같은 Wi-Fi** 또는 같은 유선 네트워크. VPN이 켜져 있으면 서로를 못 찾습니다.

## 설치

Releases에서 둘 중 하나를 받습니다. 내용물은 같습니다.

- `DeskChat-x.y.z-mac-arm64.zip` — 풀면 나오는 `데스크챗.app`을 **응용 프로그램** 폴더로 옮깁니다.
- `DeskChat-x.y.z-mac-arm64.dmg` — 열어서 `데스크챗`을 **응용 프로그램** 폴더로 끌어다 놓습니다.

예전 버전이 있다면 먼저 지우고 **휴지통을 비운 뒤** 설치해 주세요.

## 처음 실행할 때 — 두 번 막힙니다

이 앱은 애플에 공증(notarize)을 받지 않았습니다. 그래서 macOS가 두 번
막아서는데, 둘 다 통과시켜 주셔야 합니다.

### 1) "확인되지 않은 개발자" 또는 "손상되었기 때문에 열 수 없습니다"

인터넷으로 받은 파일에 macOS가 격리 표시를 붙였을 뿐, **앱이 실제로 손상된
것이 아닙니다.** 터미널에서 아래 한 줄을 실행하면 이후로는 묻지 않습니다.

```sh
xattr -cr /Applications/데스크챗.app
```

### 2) "로컬 네트워크에서 기기를 찾고 연결하도록 허용하시겠습니까?"

**허용**을 눌러 주세요. 거부하면 앱은 켜지지만 아무도 못 찾습니다.
실수로 거부했다면 시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크에서
데스크챗을 켜 주세요.

## 켜면 보이는 것

Dock 아이콘은 생기지 않습니다. 메뉴 막대(화면 맨 위 오른쪽)에 작은 아이콘
하나가 전부입니다. 처음 켜면 이름을 물어봅니다 — **8자까지, 띄어쓰기 없이.**

| 동작 | 방법 |
| --- | --- |
| 말하기 | `⌥Space` → 입력창에 쓰고 Enter |
| 감정 표현 | `⌥E` → 목록에서 고르기 |
| 직접 걷기 | `⌥←` / `⌥→` |
| 옮기기 | 캐릭터를 끌어다 놓기 |
| 이름 바꾸기 | 메뉴 막대 아이콘 → 나: ○○○ |
| 끄기 | 메뉴 막대 아이콘 → 종료 |

같은 네트워크에 있는 사람은 누구나 들어올 수 있고 대화는 암호화되지 않습니다.
민감한 얘기를 할 곳이 아닙니다.

## 서로 안 보일 때

1. 둘 다 같은 Wi-Fi인가? (게스트 망과 사내 망이 갈려 있는 경우가 흔합니다)
2. 둘 다 VPN이 꺼져 있는가?
3. 로컬 네트워크 권한을 둘 다 허용했는가?
4. 회사 Wi-Fi가 기기 간 통신을 막는 경우가 있습니다(AP isolation). 이건 앱에서 어쩔 수 없습니다.
